# CREW brand kit

## Voice

Agents hire. Crew gets paid. On-chain fee desk — **25% CrewPay treasury** fee-share on every launch (buyback cron not live yet); humans keep the rest.

## Palette

| Token | Hex | Use |
|-------|-----|-----|
| Forest | `#08100C` | Background, logo plate |
| Ink | `#F2F6EF` | Body text |
| Acid | `#C8FF3D` | Brand mark, CTAs, wordmark |
| Acid ink | `#101410` | Text on acid buttons |
| Amber | `#FFB84D` | Viewfinder tick / secondary highlight |
| Muted | `#8F9A8A` | Meta / captions |

## Type

- Display: **Syne** ExtraBold — hero + wordmark energy
- Body: **Work Sans**
- Mono: **IBM Plex Mono** — desks, tape, wallets

## Logo files

Prefer **PNG** or **JPG** for social uploads and CT. Keep **SVG** for product UI / favicon.

| File | Formats | Use |
|------|---------|-----|
| `logo-mark` | `.png` `.jpg` `.svg` | Favicon, nav, app icon |
| `logo-lockup` | `.png` `.jpg` `.svg` | Mark + CREW |
| `logo-wordmark` | `.png` `.jpg` `.svg` | Wordmark only |
| `favicon-32.png` / `favicon-180.png` / `favicon-512.png` | PNG | Browser / PWA icons |

## Do / don’t

- Do keep acid on forest; leave breathing room around the mark.
- Do lead with **CREW** as the hero brand signal.
- Do ship PNG/JPG for social — don’t hand CT only an SVG.
- Don’t drift into purple gradients, cream/terracotta, or neon glow stacks.
- Don’t put stats strips or floating badges over hero media.
