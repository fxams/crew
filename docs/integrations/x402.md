# x402 pay-per-call (no API key)

CrewPay can accept [x402](https://docs.x402.org) (HTTP **402 Payment Required**) on agent launch + Autohire. Agents pay a small **USDC** fee per request instead of claiming a `crew_ak_…` key.

Existing `x-crew-api-key` auth is unchanged. x402 is an alternative path, **off unless `X402_ENABLED` is set**.

Fee map on launches is still **60% hired KOL crew / 15% launching agent / rest treasury** (5% referrer when a referred key is bound to the payer wallet). The launching agent does not receive the 60% crew slice.

## Enablement (server)

| Variable | Purpose |
| --- | --- |
| `X402_ENABLED` | `1` / `true` to turn the feature on |
| `X402_FACILITATOR_URL` | Facilitator base URL (default `https://x402.org/facilitator`) |
| `X402_PAY_TO_EVM` | USDC recipient on Base (default `ZORA_TREASURY_ADDRESS`) |
| `X402_PAY_TO_SOL` | USDC recipient on Solana (omit to advertise Base only) |
| `X402_PRICE_LAUNCH_USD` | Launch / unsigned / submit / dry-run (default `0.10`) |
| `X402_PRICE_AUTOHIRE_USD` | Autohire (default `0.02`) |

Do not commit private keys. Pay-to addresses are public receiving wallets.

## Flow

1. `POST /api/agent/launch/unsigned` (or `/submit`, `/dry-run`, `/launch`, `/autohire`) **without** `x-crew-api-key`.
2. Server responds **402** with `x402Version: 1` and `accepts[]` (exact USDC on `base` and/or `solana`).
3. Client signs a payment and retries with header **`X-PAYMENT`** (base64 PaymentPayload).
4. Server verifies + settles via the facilitator, then fulfills the request and returns **`X-PAYMENT-RESPONSE`**.

`GET /api/kols` stays public and free.

## Identity

The **payer wallet** is the agent identity:

- Rate-limit fingerprint
- **15% launching-agent** fee-share when the payer chain matches the launch (Solana payer → Pump/Bags desk; EVM payer → Zora desk). Otherwise the `launcherPubkey` / signer still receives that slice.
- Referral: if that wallet already owns a claimed key with a KOL `referralCode`, the 5% referrer cut applies.

## MCP (`crewpay-mcp@1.2.8`)

Local stdio:

```json
{
  "mcpServers": {
    "crewpay": {
      "command": "npx",
      "args": ["-y", "crewpay-mcp@1.2.8"],
      "env": {
        "X402_EVM_PRIVATE_KEY": "0x…",
        "CREW_LAUNCHER_KEY": "your-solana-secret-base58",
        "CREW_API_URL": "https://api.crewpay.dev"
      }
    }
  }
}
```

If `CREW_AGENT_API_KEY` is set, MCP uses the key and does not pay. Hosted `mcp.crewpay.dev` never uses a shared x402 wallet — pass `x-crew-api-key` there, or run locally.

MCP signs **Base USDC**. Solana USDC is accepted by the API; SVM clients can attach `X-PAYMENT` themselves.

## Discovery

- `GET https://api.crewpay.dev/api/platforms` → `x402`
- `GET https://api.crewpay.dev/api/agent` → `auth.x402` / `platforms.x402`
- `GET https://api.crewpay.dev/llms.txt`
- OpenAPI: security scheme `X402Payment` (`X-PAYMENT`), **402** on launch + autohire
