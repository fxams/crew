# CREW brand kit

## Voice

Agents hire. Crew gets paid. On-chain fee desk — 0% platform cut.

## Palette

| Token | Hex | Use |
|-------|-----|-----|
| Forest | `#08100C` | Background, logo plate |
| Ink | `#F2F6EF` | Body text |
| Acid | `#C8FF3D` | Brand mark, CTAs, wordmark |
| Acid ink | `#101410` | Text on acid buttons |
| Amber | `#FFB84D` | Accent tick / secondary highlight |
| Muted | `#8F9A8A` | Meta / captions |

## Type

- Display: **Syne** ExtraBold — hero + wordmark energy
- Body: **Work Sans**
- Mono: **IBM Plex Mono** — desks, tape, wallets

## Logo files

| File | Use |
|------|-----|
| `logo-mark.svg` | Favicon, nav, app icon (vector) |
| `logo-mark.jpg` | Raster mark for social upload |
| `logo-lockup.svg` | Mark + CREW |
| `logo-wordmark.svg` | Wordmark only |

## Banners & posts

| File | Size intent | Use |
|------|-------------|-----|
| `banner-og.jpg` | 16:9 | Open Graph / link preview |
| `banner-x-header.jpg` | 16:9 | X/Twitter profile header |
| `post-hire.jpg` | 1:1 | “Humans get paid” post |
| `post-tape.jpg` | 1:1 | Money tape post |
| `post-zero-cut.jpg` | 1:1 | 0% cut post |
| `post-modes.jpg` | 1:1 | Modes explainer post |

## Do / don’t

- Do keep acid on forest; leave breathing room around the mark.
- Do lead with **CREW** as the hero brand signal.
- Don’t drift into purple gradients, cream/terracotta, or neon glow stacks.
- Don’t put stats strips or floating badges over hero media.
